## 从 512MB 到 16 核，哪几档真的有人该买

512MB 的 VM-0.5 价格吸引人，问题在磁盘：5GB 装完系统之后剩下的空间，跑一个纯静态站可以，想装 Docker 或者留几份备份就紧张。它的合理用途是转发、探针、极轻量的定时任务这类不吃磁盘的东西。

## 下单前容易踩的几个坑

**机房一定要手动选。** 部署页给的默认地区不一定是你想要的，套餐不绑定机房，选完才发现选错只能重装。

**香港和大阪的流量是另一套额度。** 看套餐表时 1000GB 记得对半砍，尤其是拿它做中转或代理的用途。

**支付宝要在结账页确认。** Evoxt 支持支付宝，但具体到某一笔订单、某一种币种，结账页显示什么就以什么为准，别默认它一定在第一屏。

**额外 IP 明码标价 $3/月。** 需要多 IP 的场景提前把这笔钱算进年成本，一年多 36 美元，比主机本身还贵的情况并不少见。

**退款条款没有写在价格页上。** 官方价格页列了套餐、备份、加购 IP，没有列退款窗口的具体天数。要确认能不能退、几天内退，下单前开工单问一次，比事后扯皮省事。

**流量跑超之后怎么处理，页面没有明说。** 各档的月流量额度是清楚的，超量是限速还是停机、限到多少，官方价格页没写。如果你的用途流量波动大，选档时留出余量，或者直接问客服。
